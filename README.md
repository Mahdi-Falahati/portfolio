# Mahdi Falahati – Portfolio

Static portfolio built with React and Vite.

## Run

    npm install
    npm run dev

## Build

    npm run build

The static site is generated in `dist/` and can be hosted on GitHub Pages, Netlify, Vercel or any static host.

## Edit content

All text lives in `src/data/content.js`. Styles are split by purpose in `src/styles/`.
